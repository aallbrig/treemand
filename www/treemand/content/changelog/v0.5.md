### Changed

- treemand exits with `0` on success, `1` on a runtime failure such as a CLI not found on `PATH`, and `2` on a usage error, instead of `1` for every failure.
- Running `treemand` with no CLI name prints `Error: missing CLI name` with usage and examples, and extra arguments, bad flags and an unknown completion shell get the same treatment with a hint.
- An unknown `--output` format is rejected before any discovery runs.
