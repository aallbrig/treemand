### Added

- `--output=yaml` prints the tree as YAML, and `treemand cache list` shows a table of cached CLIs with version, strategy, age and size.
- A `treemand config` command shows, validates, sets, initializes and edits your configuration file (`view`, `validate`, `set`, `init`, `path`, `edit`).
- The TUI has four display styles (default, columns, compact, graph), chosen with `--tree-style` or cycled with `T`, and `S` toggles section headers.
- `Ctrl+F` opens a global fuzzy finder over commands, flags, arguments and help text, and `/` filters the tree with `n`/`N` to step through matches.
- New TUI keys: `?` for a scrollable key-bindings overlay, `gg`/`G` to jump to the top or bottom, `d` to open a docs URL from a node's description, `r` to re-discover the selected node, `Ctrl+K` to clear the preview bar, and `Ctrl+S` to switch between arrow, vim and WASD navigation.
- Discovery shows a progress spinner, marks nodes whose discovery failed with a warning sign, and supports Cobra CLIs through their built-in completion command, with presets for aws and stripe.
- Text output ends with a note on stderr when the tree has undiscovered nodes, and `--expand-stubs` (now listed in `--help`) expands them before printing.
- treemand installs with Homebrew from its tap, and the website gains a Try page that runs the real TUI in the browser plus a documentation page for each subcommand.

### Changed

- Tree navigation follows the VS Code and Finder model: `→` expands a node and then enters its first child, `←` collapses and then moves to the parent, and moving never auto-expands; adding a flag also fills in the subcommand chain it belongs to.
- `--depth` now defaults to 3, and `-1` means unlimited depth.

### Fixed

- Release binaries now keep the discovery cache between runs.
- A CLI that leaves a background process holding its output no longer runs past `--timeout`.
- Subcommands without their own description take the one listed by their parent, and a root description comes from the man page NAME line instead of the usage synopsis.
- Discovery no longer invents subcommands from help-text lists such as "Supported formats:", and it handles wide and Go-style help layouts better.
- TUI footer hints drop whole entries on narrow terminals instead of cutting words in half.
