### Added

- An `install.sh` one-line installer for Linux and macOS downloads the release, verifies its SHA-256 checksum, and installs the binary and man page to `~/.local/bin` without elevated privileges unless you pass `--system` (other options: `--version`, `--dir`, `--no-man`, `--dry-run`).
- The website's Installation page selects your operating system and lists each working install channel with copy-ready commands.
- Release checksum files are signed with cosign, so a download can be verified against the release that built it.
- In the TUI, `PgUp`/`PgDn` and `Ctrl+U`/`Ctrl+D` move a screenful at a time through the tree, and the footer shows `?:keys` in every navigation scheme.

### Changed

- Cached runs no longer start the CLI at all: the cache is keyed on the executable file on disk instead of its `--version` output, so warm runs of slow-starting CLIs such as aws and pip return almost instantly.
- Expand-all (`e`) on very large trees such as a fully expanded aws is about seven times faster.
- The website has page titles and descriptions, a social preview card, favicons, and accessibility fixes for contrast, headings and link names.

### Fixed

- The `?` key-bindings overlay fits the terminal height, wraps long lines, and lists bindings it was missing (page keys, `Space`, `Ctrl+C`, the mouse).
- A CLI without a `--version` command now picks up a fresh cache entry after it is upgraded instead of being served a stale tree.
