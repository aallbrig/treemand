### Added

- `--refresh` re-discovers a CLI and replaces its cache entry, and the `cache_ttl_hours` setting controls how long entries are trusted (default 30 days, `0` means until the CLI changes).
- `install.sh` verifies the release signature with cosign when cosign is installed, and `--require-signature` refuses to install without it.

### Changed

- The website, installer and release downloads moved to treemand.dev.
- `treemand -i` opens as soon as the root is read and discovers the rest in the background, showing `discovering… n/total` in the status bar.
- Cache entries no longer expire after 24 hours, and subtrees you expand in the TUI are saved to the cache for the next session.
- Discovery learns which help form each CLI answers and uses it for every subcommand, which roughly halves cold discovery time for CLIs like aws.
- The parser reads many more option shapes, such as `-n, --quiet, --silent`, `--jobs[=N]` and `-pl,--projects <arg>`, adding flags for make, sed, node, rg, mvn and git.
- On phones the website's navigation collapses behind a menu button.

### Fixed

- Discovery no longer runs commands that could act on your system: `list-commands` is sent only to CLIs that document it (it had created a file in the current directory for `touch`), and a help request that times out never falls back to forms like `<cmd> <sub> help`.
- A CLI whose `--version` hangs no longer hangs treemand.
- Help output that starts with a warning (such as flask's) is read as help, and a short usage error is no longer mistaken for help.
- Phantom subcommands from value lists, library version rows and usage continuations are gone, and descriptions come from prose rather than version or copyright banners (ffmpeg, rsync, ruby, tar, java).
