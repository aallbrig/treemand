### Added

- treemand.dev has a light and dark theme with a header toggle that remembers your choice, and every code block has a copy button.
- The treemand.dev home page shows a live, expandable kubectl tree and the install one-liner in macOS, Linux and Windows tabs.
- Documentation pages have a sidebar, an "On this page" outline, previous and next links, heading anchors and an "Edit this page on GitHub" link.
- Site search opens from the header or with `Cmd+K`, `Ctrl+K` or `/`, and the site publishes an `llms.txt` for agents.

### Changed

- The parser covers many more CLI families: argparse subparsers (pipx, pre-commit), single-dash long options (gofmt, terraform), kingpin, thor, yarn 1, busybox and openssl command lists, man-page command references (bundle), `OBJECT` grammars (ip), and poetry through its `list` command; systemctl gains 17 missing commands.
- Discovery starts fewer help processes: the aws root needs one help call instead of three, and gh discovery starts about half as many processes as before.
- Expand-all in the TUI allocates far less memory on large trees.

### Fixed

- TUI rows wider than their pane are truncated with an ellipsis instead of wrapping, so the frame always fits the terminal.
- On macOS, BSD tools that answer `--help` with an "illegal option" usage message are read from that message instead of being sent `help` as an argument (which made `mkdir` create a `help` directory).
