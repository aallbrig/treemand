### Added

- `--output=json` now has a versioned JSON Schema, printed by the new `treemand schema` command and published at treemand.dev/schema/tree.v1.json.
- JSON and YAML output carry `schema_version: 1` on the root node, and the Reference and Output pages state the compatibility promise: within a version the output only gains optional properties.

### Changed

- YAML output uses the same keys as JSON (`full_path`, `help_text` and so on, instead of `fullpath` and `helptext`) and leaves out empty fields; scripts that read the old YAML keys need updating.
