Installation

Pick your system and copy the commands. We guess your system from your browser; use the buttons to change it. The install script and the release archives are checksum-verified, and nothing here needs admin rights unless you ask for --system.

macOS

Homebrew Recommended

Installs and updates treemand and its man page.

brew tap aallbrig/tap
brew install treemand

Install script

Downloads the release for your Mac (Apple Silicon or Intel), verifies its SHA-256 checksum and installs to ~/.local/bin. No admin rights needed.

curl -fsSL https://aallbrig.github.io/treemand/install.sh | sh

Release binary

Download treemand_darwin_arm64.tar.gz (Apple Silicon) or treemand_darwin_amd64.tar.gz (Intel) from the latest release, then:

tar xzf treemand_darwin_arm64.tar.gz
mv treemand_darwin_arm64 /usr/local/bin/treemand

Go

Needs Go 1.26 or newer. The binary lands in $GOPATH/bin (usually ~/go/bin).

go install github.com/aallbrig/treemand/cli/treemand@latest

Linux

Install script Recommended

Downloads the release for your CPU (amd64 or arm64), verifies its SHA-256 checksum and installs to ~/.local/bin with the man page. No root needed; add --system for /usr/local/bin.

curl -fsSL https://aallbrig.github.io/treemand/install.sh | sh

Homebrew

Works with Homebrew on Linux.

brew tap aallbrig/tap
brew install treemand

Release binary

Download treemand_linux_amd64.tar.gz or treemand_linux_arm64.tar.gz from the latest release, check it against checksums.txt, then:

sha256sum -c --ignore-missing checksums.txt
tar xzf treemand_linux_amd64.tar.gz
install -m 0755 treemand_linux_amd64 ~/.local/bin/treemand

Go

Needs Go 1.26 or newer. The binary lands in $GOPATH/bin (usually ~/go/bin).

go install github.com/aallbrig/treemand/cli/treemand@latest

Windows

Release binary (PowerShell) Recommended

Downloads the zip, unpacks it into %USERPROFILE%\bin and names it treemand.exe. Add that folder to your PATH. These steps are not run in CI. In WSL, use the Linux install script instead.

$dir = "$env:USERPROFILE\bin"; New-Item -ItemType Directory -Force $dir | Out-Null
Invoke-WebRequest https://github.com/aallbrig/treemand/releases/latest/download/treemand_windows_amd64.zip -OutFile treemand.zip
Expand-Archive -Force treemand.zip -DestinationPath $dir
Move-Item -Force "$dir\treemand_windows_amd64.exe" "$dir\treemand.exe"

Go

Needs Go 1.26 or newer. The binary lands in %GOPATH%\bin.

go install github.com/aallbrig/treemand/cli/treemand@latest

Install script options

The script is install.sh: read it before you pipe it to a shell, and run it with --help for every option. The checksum guards against a corrupted or truncated download; it comes from the same GitHub release as the archive, so it does not defend against a compromised release.

curl -fsSL https://aallbrig.github.io/treemand/install.sh | sh -s -- --version v0.6.1   # a specific release
curl -fsSL https://aallbrig.github.io/treemand/install.sh | sh -s -- --dir ~/bin         # another directory
curl -fsSL https://aallbrig.github.io/treemand/install.sh | sh -s -- --system            # /usr/local/bin, asks for admin rights only if needed
curl -fsSL https://aallbrig.github.io/treemand/install.sh | sh -s -- --dry-run           # show what it would do

Build from source

Requires Go 1.26+.

git clone https://github.com/aallbrig/treemand.git
cd treemand/cli/treemand
go build -o treemand .

Shell completions

After installing, set up completions for your shell:

# Bash — add to ~/.bashrc
source <(treemand completion bash)

# Zsh — add to ~/.zshrc
source <(treemand completion zsh)

# Fish
treemand completion fish > ~/.config/fish/completions/treemand.fish

# PowerShell — add to profile
treemand completion powershell | Out-String | Invoke-Expression

Verify the installation

treemand version
# prints the version, commit and build date

Update or uninstall

Re-run the install script (or brew upgrade treemand) to update. To uninstall a script install, delete ~/.local/bin/treemand and ~/.local/share/man/man1/treemand.1; for Homebrew, brew uninstall treemand.
