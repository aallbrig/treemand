# Tools a treemand dev host needs: the one list that scripts/dev/setup.sh
# (installs) and scripts/dev/bootstrap.sh (reports) both read.
#
# name|need|brew|apt|dnf|fallback
#   name      command looked up on PATH (node, chrome, hugo, dlv and gopls-lsp have special checks in tools.sh)
#   need      required: task ci needs it; setup.sh exits non-zero while one is missing
#             optional: the dev session or agent tooling uses it; reported only
#   brew/apt/dnf  package for that manager (cask:<name> for a brew cask), or - for none
#   fallback  used when the manager column is -:
#             go:<module@version>  pipx:<package>  gem:<package>  nvm (installs .nvmrc's node)
#             claude-plugin:<plugin@marketplace>  (Claude Code plugin, user scope)
#             url:<page>  (no automatic install; the page says how)
#
# Order matters: system packages install first, so go and pipx exist for the fallbacks.
