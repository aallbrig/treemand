# Every other shell script is POSIX sh (#!/bin/sh), linted with
# `shellcheck --shell=sh -S warning` (task shell:check) and run under dash.
# This list is the migration backlog: the shell-portability probe counts it
# (exempt_scripts) and its ratchet only lets it shrink. Migrate a script, then
# delete its line here; never add a line for a new script.
