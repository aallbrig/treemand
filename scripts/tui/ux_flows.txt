# Task flows for scripts/tui/ux_evidence.sh. One step per line:
#   flow|target|step|keys
# Every flow starts a fresh TUI on its target; its first step is the opened
# frame. Steps run in order and each ends with a captured frame.
#   target  the CLI to open (@broken is a fake CLI whose help fails; @missing
#           is a name on no PATH); only a flow's first line needs it
#   keys    space-separated tmux key names (Down, Right, Enter, Escape, C-e,
#           BSpace, PageDown, ...) or lit:TEXT to type TEXT; empty = no keys
# Safety: Enter, r and R in the command modal (C-e) run the command. Close it
# with Escape. Never press c there either (it writes the system clipboard).
# Never press d or D in a flow: they open a browser.
