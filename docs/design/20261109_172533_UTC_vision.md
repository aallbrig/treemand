# treemand vision

## What treemand is

treemand makes any CLI's command hierarchy visible and usable. It reads a tool's
own `--help` (and man pages and completions), builds the tree, and lets you
explore it as static output or an interactive TUI that assembles a real command
line you can copy or run.

## Who it is for

- Developers meeting an unfamiliar CLI (kubectl, docker, gh, aws) who want the
  whole shape of it in seconds instead of ten `--help` round trips.
- People who know a CLI exists but not the exact flag, and want to find and
  assemble it by browsing or fuzzy search.
- Scripts and agents that need a machine-readable map of a CLI (JSON/YAML).

## Principles

1. **Zero setup, any CLI.** Works on tools that never heard of treemand. Discovery
   quality on messy real-world help output is the core product.
2. **Fast and honest.** Cached trees are instant; stale or partial results are
   labelled, never silently wrong.
3. **A TUI worth keeping open.** Keyboard-first, mouse-friendly, legible at 80x24,
   good at 200 columns, no flicker, no dead ends.
4. **Looks professional everywhere.** The website, the demos, the TUI and the
   README should feel like one considered product.
5. **Small, safe releases.** One change per release, always revertable.

## Where it is going (loop: pick from here when idle)

- Discovery that handles more CLI families with fewer stub nodes (nonstandard
  help layouts, subcommand aliases, plugin-style CLIs).
- Search and navigation that make 500-command CLIs pleasant (fuzzy search, jump,
  bookmarks, recent commands).
- Command assembly: value prompts, enum choices from help text, shell-quoted
  output, one-key copy/run.
- A polished website: clear landing page, the Try page as the hero, per-CLI
  gallery of pre-rendered trees, fast and accessible on mobile.
- Agent-facing surface: a stable JSON schema and, as an *exploration*, an MCP
  server or subcommand. Propose first; build only when promoted to `loop:ready`.
- Distribution: Homebrew, Scoop, AUR, Snap, Chocolatey all current and verified.

## Out of scope

- Executing discovered commands on the user's behalf without an explicit action.
- Telemetry that leaves the machine.
- A `1.0.0` declaration. That is the maintainer's call.
