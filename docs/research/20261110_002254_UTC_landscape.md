## Spec ecosystems

- [Fig / withfig autocomplete](https://fig.gitbook.io/fig/autocomplete): TypeScript spec tree of Command/Option/Arg; large community spec repo. Possible data source for richer flag metadata.
- [carapace-spec](https://pkg.go.dev/github.com/carapace-sh/carapace-spec) / carapace-bin: YAML spec plus completion engine in Go, generators for urfave/cli and oclif.
- [usage (jdx)](https://usage.jdx.dev): language-neutral CLI spec, "OpenAPI for CLIs"; generates completions, markdown docs, man pages, Fig specs. An export target worth considering: `treemand --output=usage`.

## Distribution and project hygiene (Go CLI norm)

- [GoReleaser](https://goreleaser.com/blog/goreleaser-v1.19): one config produces archives, checksums, Homebrew/Scoop/Krew PRs, winget manifests, nix; templates for PRs. treemand hand-rolls this in `release.yml`.
- Multi-channel distribution beyond `go install` is the stated norm ([DEV article](https://dev.to/_402ccbd6e5cb02871506/shipping-a-go-cli-to-every-ecosystem-github-releases-homebrew-and-npm-5g27)).
- Search returned nothing usable on SECURITY.md, issue templates or README conventions: use the GitHub community-standards checklist instead.

## Where treemand can lead

Peers stop at viewing. treemand already assembles and runs commands, ships a browser Try page and
caches. Open ground: richer metadata via completions or Fig/carapace specs, a published
tested-CLIs matrix with a regression corpus, a documented JSON Schema and agent/MCP surface, and
a spec export (usage/Fig).

### Reading it honestly

Where peers are ahead today: mandible's multi-source discovery, framework detection, `--doctor`,
overrides and probe isolation; mandible's and helptree's start-instantly tree that fills in
(treemand waits for discovery, #68); cli-tree's pipe mode and HTML output and its larger claimed
tested list (53+ against 16); te-cli's history and presets; mandible's `.deb` and `.rpm`.

Where treemand leads: it is the only one here that combines browsing with command assembly and
running, a browser Try page, a persistent cache, machine-readable JSON and YAML, Windows builds
(mandible documents Linux and macOS only), and published regression evidence (corpus baseline, fuzzing, chaos and end-to-end suites). Claims
about peers stay unverified until #101 is done.
