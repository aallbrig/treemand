Interactive TUI (-i)

The interactive mode launches a full-screen terminal explorer with three panes: a live preview bar, a navigable tree pane, and a help pane that shows --help output for the currently selected node.

Launch #

treemand -i git
treemand -i kubectl
treemand -i docker

The TUI opens as soon as the CLI’s top-level help is read, usually in well under a second, even for CLIs with hundreds of subcommands. The rest is discovered in the background: the status bar shows discovering… 37/233, and commands fill in without moving your selection. Everything discovered is cached, so the next run opens complete. If you quit early, the next run picks up where this one stopped.

Workflow #

  1. Navigate — ↓/↑ (or j/k) to browse; cursor never auto-expands
  2. Expand — → opens a node, press again to enter its children
  3. Pick a command — Enter sets it in the preview bar
  4. Add flags — f to open the flag picker; Enter on a flag row adds it directly
  5. Fill positionals — Enter on a positional row opens an input prompt
  6. Copy or run — Ctrl+E opens a confirmation modal: copy to clipboard or execute

Mouse support #

Click any node to select it, click ▶/▼ to expand/collapse, and scroll to navigate. Click the preview bar to focus it for direct text editing.

Navigation schemes #

treemand supports three keyboard navigation schemes. Press Ctrl+S to cycle:
