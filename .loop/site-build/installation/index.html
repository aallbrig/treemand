Installation

Pick your system and copy the commands. We guess your system from your browser; use the buttons to change it. The install script verifies each release’s signature and checksum, and nothing here needs admin rights unless you ask for --system.

macOS

Homebrew Recommended

Installs and updates treemand and its man page.

brew tap aallbrig/tap
brew install treemand

Install script

Downloads the release for your Mac (Apple Silicon or Intel), verifies its signature (with cosign) and SHA-256 checksum, and installs to ~/.local/bin. No admin rights needed.

curl -fsSL https://treemand.dev/install.sh | sh

Release binary

Download treemand_darwin_arm64.tar.gz (Apple Silicon) or treemand_darwin_amd64.tar.gz (Intel) from the latest release, then:

tar xzf treemand_darwin_arm64.tar.gz
mv treemand_darwin_arm64 /usr/local/bin/treemand

Go (from source)

Needs Go 1.26 or newer. Builds the current source; the binary lands in $GOPATH/bin (usually ~/go/bin).

git clone --depth 1 https://github.com/aallbrig/treemand.git && cd treemand/cli/treemand && go install .

Linux

Install script Recommended

Downloads the release for your CPU (amd64 or arm64), verifies its signature (with cosign) and SHA-256 checksum, and installs to ~/.local/bin with the man page. No root needed; add --system for /usr/local/bin.

curl -fsSL https://treemand.dev/install.sh | sh

Homebrew

Works with Homebrew on Linux.

brew tap aallbrig/tap
brew install treemand

Release binary

Download treemand_linux_amd64.tar.gz or treemand_linux_arm64.tar.gz from the latest release, check it against checksums.txt, then:

sha256sum -c --ignore-missing checksums.txt
tar xzf treemand_linux_amd64.tar.gz
install -m 0755 treemand_linux_amd64 ~/.local/bin/treemand

Go (from source)

Needs Go 1.26 or newer. Builds the current source; the binary lands in $GOPATH/bin (usually ~/go/bin).

git clone --depth 1 https://github.com/aallbrig/treemand.git && cd treemand/cli/treemand && go install .

Windows

Release binary (PowerShell) Recommended

Downloads the zip, unpacks it into %USERPROFILE%\bin and names it treemand.exe. Add that folder to your PATH. These steps are not run in CI. In WSL, use the Linux install script instead.

$dir = "$env:USERPROFILE\bin"; New-Item -ItemType Directory -Force $dir | Out-Null
$v = (Invoke-RestMethod https://treemand.dev/releases/latest.txt).Trim()
Invoke-WebRequest "https://treemand.dev/releases/$v/treemand_windows_amd64.zip" -OutFile treemand.zip
Expand-Archive -Force treemand.zip -DestinationPath $dir
Move-Item -Force "$dir\treemand_windows_amd64.exe" "$dir\treemand.exe"

Go (from source)

Needs Go 1.26 or newer. Builds the current source; the binary lands in %GOPATH%\bin.

git clone --depth 1 https://github.com/aallbrig/treemand.git; cd treemand\cli\treemand; go install .

Install script options #

The script is install.sh: read it before you pipe it to a shell, and run it with --help for every option. It downloads from https://treemand.dev/releases/. Every release’s checksums.txt is signed by this repository’s release workflow (Sigstore, no private key involved). With cosign installed, the script refuses anything that signature doesn’t vouch for, which protects you from a tampered download or mirror. Without cosign it still checks the SHA-256 checksum, which catches a corrupted or truncated download; add --require-signature to refuse installing without cosign.

curl -fsSL https://treemand.dev/install.sh | sh -s -- --require-signature # refuse to install unless cosign verifies it
curl -fsSL https://treemand.dev/install.sh | sh -s -- --version v0.6.2   # a specific release
curl -fsSL https://treemand.dev/install.sh | sh -s -- --dir ~/bin         # another directory
curl -fsSL https://treemand.dev/install.sh | sh -s -- --system            # /usr/local/bin, asks for admin rights only if needed
curl -fsSL https://treemand.dev/install.sh | sh -s -- --dry-run           # show what it would do

Linux packages #

Each release from v0.10.0 on also ships .deb, .rpm and .apk packages for amd64 and arm64. They install treemand to /usr/bin and its man page, and your package manager can remove it again. The package checksums are in the release’s signed checksums.txt.

# Debian, Ubuntu
curl -fsSLO https://github.com/aallbrig/treemand/releases/latest/download/treemand_linux_amd64.deb
sudo apt install ./treemand_linux_amd64.deb

# Fedora, RHEL
sudo dnf install https://github.com/aallbrig/treemand/releases/latest/download/treemand_linux_amd64.rpm

# Alpine
curl -fsSLO https://github.com/aallbrig/treemand/releases/latest/download/treemand_linux_amd64.apk
sudo apk add --allow-untrusted ./treemand_linux_amd64.apk

On arm64, replace amd64 with arm64. Each archive also has a software bill of materials (SPDX JSON) next to it on the release page, named after the archive with .sbom.json added.

Verify a download by hand #

Releases after v0.10.1 carry a build provenance attestation for every archive and package: a signed statement that this repository’s release workflow built that exact file. With the GitHub CLI, check any file you downloaded from the release page:

gh attestation verify treemand_linux_amd64.tar.gz --repo aallbrig/treemand

To check the signed checksum list itself, as the install script does, use cosign (replace vX.Y.Z with the release):

cosign verify-blob \
  --bundle checksums.txt.sigstore.json \
  --certificate-identity "https://github.com/aallbrig/treemand/.github/workflows/release.yml@refs/tags/vX.Y.Z" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  checksums.txt
sha256sum --check --ignore-missing checksums.txt

Build from source #

Requires Go 1.26+. (go install …@latest doesn’t work yet: the Go module lives in cli/treemand/, so there is no remote install path. Build from a checkout instead.)

git clone https://github.com/aallbrig/treemand.git
cd treemand/cli/treemand
go build -o treemand .

Shell completions #

After installing, set up completions for your shell:

# Bash — add to ~/.bashrc
source <(treemand completion bash)

# Zsh — add to ~/.zshrc
source <(treemand completion zsh)

# Fish
treemand completion fish > ~/.config/fish/completions/treemand.fish

# PowerShell — add to profile
treemand completion powershell | Out-String | Invoke-Expression

Verify the installation #

treemand version
# prints the version, commit and build date

Update or uninstall #

Re-run the install script (or brew upgrade treemand) to update. To uninstall a script install, delete ~/.local/bin/treemand and ~/.local/share/man/man1/treemand.1; for Homebrew, brew uninstall treemand.
