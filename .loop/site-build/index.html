Every command of any CLI, as a tree

treemand reads a tool's help and maps its subcommands, flags and arguments into a tree you can browse, search, and turn into a command to copy or run.

Try it in your browser Get started
macOS · Homebrew
brew tap aallbrig/tap
brew install treemand
Linux · Install script
curl -fsSL https://treemand.dev/install.sh | sh
Windows · Release binary (PowerShell)
$dir = "$env:USERPROFILE\bin"; New-Item -ItemType Directory -Force $dir | Out-Null
$v = (Invoke-RestMethod https://treemand.dev/releases/latest.txt).Trim()
Invoke-WebRequest "https://treemand.dev/releases/$v/treemand_windows_amd64.zip" -OutFile treemand.zip
Expand-Archive -Force treemand.zip -DestinationPath $dir
Move-Item -Force "$dir\treemand_windows_amd64.exe" "$dir\treemand.exe"
